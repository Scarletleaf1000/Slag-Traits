[![Modrinth](https://img.shields.io/modrinth/dt/slag-n-traits?logo=modrinth&label=Modrinth&color=00AF5C)](https://modrinth.com/mod/slag-n-traits)

[![GitHub Repo](https://img.shields.io/github/stars/ScarletLeaf1000/slag-traits?logo=github&label=Stars&color=181717)](https://github.com/ScarletLeaf1000/slag-traits)

An addon to Slag n' Embers that adds data driven traits to the tools.

## Features
- Data-driven traits
- Many effects for traits
- Innate material traits

## Dependencies/Compatibility
- Requires [Slag n' Embers](https://modrinth.com/mod/slag-n-embers)
- [Slag n' Traits Default Traits Pack](https://modrinth.com/mod/slag-default-traits) is recommended
_ _ _
Feel free to use this mod in any modpack you create or make addons for it!
